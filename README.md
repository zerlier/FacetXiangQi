# ⚔ 命石象棋

> **在标准中国象棋的基础上，为每个棋子赋予独特的「命石」能力，创造全新的策略博弈体验。**

**思路来源**：[知乎 · 如果中国象棋的每个棋子都有技能，会怎样？](https://www.zhihu.com/question/426985535/answer/3515877778)

---

## 📖 简介

命石象棋是一款基于经典中国象棋规则的变体棋类游戏。在标准象棋走法的基础上，引入了「命石」系统——对局前，玩家可以为己方每个棋子选择一枚命石，赋予其独特的特殊能力。同一盘棋中，不同的命石搭配会产生截然不同的战术风格和攻防节奏。

### 亮点

- **16 种命石**，覆盖全部 7 种棋子类型，每种都有独特的机制
- **隐藏信息博弈**：人机模式下对方命石不可见，需在对弈中推理
- **AI 对手**：Alpha-Beta 搜索 + 命石感知评估，三档难度
- **双版本**：Python (Pygame) 桌面版 + Web (HTML5 Canvas) 浏览器版

## 🎮 游戏流程

```
命石配置 → 开始对弈 → 对局进行 → 胜负判定 → 再来一局
```

1. **选择模式**：双人对弈 / 人机对弈
2. **配置命石**：为己方棋子自由选择命石（支持随机配置）
3. **对弈**：标准象棋规则 + 命石特殊效果
4. **结算**：一方将帅被消灭则判负

## 💎 命石一览

每个棋子可装备一枚命石。命石在开局前选定，对局中不可更换。

### 兵 / 卒

| 命石 | 效果 |
|------|------|
| **陷阵** | 可向前突进两格取代通常移动，吃掉经过的所有敌方棋子（不可穿过友军） |
| **卫兵** | 不再能过河，但在过河前即可左右移动（仍不可后退） |
| **伏兵** | 本方前 8 回合内若未移动过，被吃时吃子的敌方棋子也一起阵亡（同归于尽） |

### 炮 / 砲

| 命石 | 效果 |
|------|------|
| **野战炮** | 前三次移动不能吃子，但本场可不需要炮架直接吃子一次 |
| **重炮** | 吃子时同时消灭目标身后一格的敌方棋子；吃子后下一回合不能行动（眩晕） |

### 士 / 仕

| 命石 | 效果 |
|------|------|
| **近卫** | 不再斜走，改为直线走法；单次可在同一方向移动至多 2 格（仅能吃子一次） |
| **巡营** | 出生点改为九宫格顶角，可以离开九宫格但不能过河 |

### 将 / 帅

| 命石 | 效果 |
|------|------|
| **斗将** | 若与敌将同列且之间仅有己方棋子阻拦，可消耗一步直接吃掉对面的将 |
| **宿将** | 将被吃后不会立即判负，需再消灭任一个己方相/象之后才会判负 |

### 相 / 象

| 命石 | 效果 |
|------|------|
| **督军** | 抵达河边时可消耗一步前往对岸对应位置，该移动可以吃子 |
| **事急从权** | 可以往前一步取代田字走法，该特殊移动不可吃子 |

### 马

| 命石 | 效果 |
|------|------|
| **轻骑** | 不再会被拌马腿（忽略蹩脚），但不能吃车 |
| **游牧佣军** | 开局与相邻的己方车互换位置，在己方所有车阵亡之前不可移动 |
| **拐子马** | 己方马或兵在其攻击范围内被吃时，可免费反击消灭吃子的敌方棋子 |

### 车

| 命石 | 效果 |
|------|------|
| **掠袭** | 吃子前至少移动 6 格，则吃子后可再移动最多 3 格（不可吃子，直线无阻挡） |
| **横行** | 可越过己方棋子攻击敌方棋子，但消灭路过的所有己方棋子 |

## 🤖 AI 系统

### 搜索算法

- **Alpha-Beta 剪枝** + **迭代加深**
- 超时保护：3 秒
- 搜索宽度限制：depth ≥ 3 时 15 分支，depth ≥ 2 时 20 分支，否则 30 分支

### 难度等级

| 难度 | 搜索深度 |
|------|---------|
| 简单 | 2 层 |
| 中等 | 3 层 |
| 困难 | 4 层 |

### 评估函数

- 基础子力价值（将 100000 / 车 900 / 炮 420 / 马 400 / 士 200 / 象 200 / 兵 100）
- 位置价值表（兵、马、车、炮各有 10×9 的位置加成矩阵）
- 命石效果评估（每种命石根据当前局面给出动态分值）
- 机动性加成（合法步数 × 3）
- 将帅安全性（周围保护子数 + 是否被直接攻击）
- MVV-LVA 走法排序优化剪枝效率

### AI 命石选择

AI 使用加权随机策略为己方棋子选择命石：

- **高权重**：轻骑(5)、宿将/伏兵/重炮(4)
- **中权重**：掠袭/巡营/督军/斗将/拐子马(3)
- **低权重**：游牧佣军(0.5)

## 🎨 特殊机制详解

### 掠袭二次移动

掠袭车在吃子前移动 ≥ 6 格时触发。吃子后高亮显示 3 格范围内的直线空位，玩家可选择继续移动或跳过。

### 拐子马反击

当己方马或兵在拐子马攻击范围内被吃时，如果拐子马也能攻击到吃子者的当前位置，触发反击选项。确认后吃子者阵亡，拐子马移动到该位置。

### 重炮穿透 + 眩晕

吃子时沿攻击方向额外消灭目标身后一格的敌方棋子。代价是吃子后眩晕一回合不能行动。

### 伏兵同归于尽

本方前 8 回合内，未移动的伏兵被吃时触发。伏兵死亡，吃子方棋子也一起阵亡。超过 8 回合或移动后失效。

### 宿将机制

将被吃后游戏不会立即结束。需要同时消灭该方所有相/象才会判负。

### 斗将

将与敌将同列，中间有且仅有己方棋子阻拦时，可消耗一步直接吃掉对面的将。是最强力的终结技。

## 🖥 界面说明

### Pygame 桌面版

- **命石配置页**：卡片式命石选择，支持随机配置和窗口大小调整
- **对局界面**：
  - 棋盘区：标准 9×10 棋盘，含九宫格斜线、楚河汉界、星位标记
  - 右侧面板：回合信息、行动记录 / 命石总览 Tab 切换
  - 底部面板：窗口大小选择（小/中/大/全）
- **视觉效果**：
  - 命石光环脉冲动画
  - 棋子移动 ease-out 缓动
  - 吃子闪烁 + 粒子特效
  - 眩晕 / 伏兵激活状态标记
- **悬浮详情**：鼠标悬停棋子 150ms 后显示命石详情（对方命石显示为「???」）
- **HiDPI 适配**：2x 离屏画布 + smoothscale，macOS Retina 下清晰显示

### Web 浏览器版

- 命石配置下拉框 + 效果描述
- Canvas 640×710 渲染
- 右键查看命石详情
- 查看命石按钮弹窗
- AI 思考时遮罩禁止操作
